
# Student Registration System

## About the Project
A web-based Student Registration System developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features
- Student Registration
- Student Login and Dashboard
- Admin Login and Dashboard
- View Students
- Search Students
- Edit Student Records
- Delete Student Records
- Student Profile Management

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- WAMP Server

## Installation
1. Install WAMP Server.
2. Copy the project folder into the WAMP www directory.
3. Create the database using phpMyAdmin.
4. Configure the local database connection in config.php.
5. Open the project through localhost in your browser.

## Security
- Password hashing
- Prepared SQL statements
- Session-based authentication
- CSRF protection

## Project Purpose
This project was developed for learning web development and database management.
